Gitee 是 OSCHINA 推出的基于 Git 的代码托管平台（同时支持 SVN）。专为开发者提供稳定、高效、安全的云端软件开发协作平台

#### 📁 文件夹说明

| 文件夹名称 | 说明 |
|------------|------|
| `aisc/`     | ASIC 实现相关文件，包括约束文件、综合脚本、比特流生成配置等。 |
| `ci/`       | 持续集成脚本与配置文件，用于自动化测试、构建和部署流程。 |
| `doc/`      | 项目文档，包括架构说明、使用手册、API 文档等。 |
| `ips/`      | 项目中使用到的 IP 核（如 UART、SPI、GPIO 等）的 RTL 源码与配置文件。 |
| `rtl/`      | 核心 RTL 源码目录，包含处理器核、总线、内存接口等硬件设计文件。 |
| `sw/`       | 软件部分，包括启动代码、运行时库、驱动程序、示例程序等。 |
| `tb/`       | 测试平台（Testbench）目录，用于功能仿真和验证 RTL 设计。 |
| `vsim/`     | 仿真工具（如 ModelSim）脚本与配置文件，用于运行仿真和查看波形。 |
